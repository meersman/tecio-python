# MATLAB Plugins

The MATLAB helpers read Tecplot data written by {mod}`~tecio.cli.tec2mat` and
plot unstructured surface zones. Add the `plugins/matlab` folder to your
MATLAB path to use them.

```bash
export MATLABPATH=/path/to/share/tecio/plugins/matlab
```
